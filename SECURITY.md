# Security reports / 安全问题

Do not disclose sensitive vulnerabilities, private files, or exploit samples in a public Issue. Use this repository's **Security → Report a vulnerability** private reporting feature when enabled. If it is unavailable, open a non-sensitive Issue asking for a private contact method, without technical exploit details.

请勿在公开 Issue 中发布敏感漏洞、私人文件或攻击样本。优先使用仓库 Security → Report a vulnerability 的私密报告；如果暂未启用，只公开询问私密联系方式，不披露漏洞细节。

There is no automatic security-report upload from the application. / 应用不会自动上传安全报告。
